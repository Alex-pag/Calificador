Calificador automático

El profesor sube su documento modelo y la página obtiene sus métricas clave. El alumno sube su trabajo y se compara con ese modelo para darle una nota del 0 al 20. Todo se procesa en el navegador: los archivos no se envían a ningún servidor.

3 Forma de calificar y compartir

Modo

Compartir con los alumnos

Envía el enlace a tus alumnos: al abrirlo verán solo la vista de alumno, con estos criterios, y podrán subir su documento para ver su nota. También puedes darles el código para que lo peguen en la pestaña «Alumno».

Esta página está abierta desde un archivo de tu computadora, así que el enlace solo funcionará aquí. Para que funcione en otros equipos, publica la página (por ejemplo, con GitHub Pages) o comparte el código.
